# Unemployment Analysis using Python (CodeAlpha Internship - Task 2)

This repository contains the source code and datasets for **Task 2** of the CodeAlpha Data Science Internship. The goal of this project is to analyze the unemployment rate in India across different regions and states, particularly highlighting trends during economic shifts and the COVID-19 pandemic.

---

## 📊 Project Overview
Unemployment is a critical economic indicator. This project processes historical unemployment datasets from India to compute state-wise average unemployment rates, examine data distributions, and visualize regional disparities using Python.

---

## 🛠️ Tech Stack & Libraries
* **Language**: Python
* **Environment**: Jupyter Notebook (`.ipynb`)
* **Libraries**: 
  * `pandas` & `numpy` (Data cleaning, handling, and preprocessing)
  * `matplotlib` (Data visualization and plotting)

---

## 📂 Repository Contents
1. **`unemployment_analysis.ipynb`**: The primary Jupyter Notebook containing data analysis, aggregations, and plotting scripts.
2. **`Unemployment_Rate_upto_11_2020.csv`**: Primary dataset containing state-wise and region-wise monthly unemployment rates up to November 2020.
3. **`Unemployment in India.csv`**: Supplemental historical dataset containing rural and urban employment statistics.
4. **`unemployment_analysis_plot.png`**: Visual bar chart showing the average unemployment rates by region.

---

## 📈 Key Insights & Visualization
* Computed state-wise average estimated unemployment rates to identify regions facing higher employment challenges.
* Visualized comparative figures using a horizontal bar plot to provide clear insights at a glance.
* *Refer to `unemployment_analysis_plot.png` in the repository for the detailed visual breakdown.*
